# Sudoku
Kiro generated sudoku

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed.

### Install dependencies
```bash
npm install
```

### Start the app
```bash
npm run serve
```

This starts a local static server. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:3000`).

## Other Commands

Run tests:
```bash
npm test
```

Run linter:
```bash
npm run lint
```
